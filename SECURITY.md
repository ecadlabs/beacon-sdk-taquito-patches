# Security Policy

Please report security-sensitive issues privately through GitHub Security
Advisories for this repository:

<https://github.com/ecadlabs/beacon-sdk-taquito-patches/security/advisories/new>

For non-sensitive defects, use the public issue templates instead.

## Scope

This policy covers the ECAD-maintained `@ecadlabs/beacon-*` packages published
from this repository.

## What helps

Include the affected package name and version, transport or wallet details, a
minimal reproduction, and whether the issue is exploitable remotely or requires
user interaction.
